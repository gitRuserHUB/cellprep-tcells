# CellPrep · T 细胞分选用量计算器

输入细胞计数 n，选择 10⁶ 或 10⁷，即时计算缓冲液、抗体和磁珠用量。全部以 μL 显示，保留三位小数。

- 抗体阶段 0.5% BSA/PBS：每 10⁶ 个细胞 5 μL。
- CD11b：每 10⁶ 个细胞 0.015 μL。
- CD49b、CD45R：每 10⁶ 个细胞各 0.030 μL。
- 磁珠阶段 0.5% BSA/PBS：每 10⁶ 个细胞 10 μL。
- 磁珠用量：三种抗体总量的两倍。

缓冲液按细胞数直接计算，不扣除抗体或磁珠体积。合计按未舍入值计算。

无需登录。计算在浏览器内完成，细胞计数不会上传。10 × 10⁶ 和 1 × 10⁷ 的结果相同。

此仓库为 CellPrep 独立 GitHub Pages 发布源码。
